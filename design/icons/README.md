# Lisan app icon (chosen by the owner on 2026-11-23)

Four tiles, one per course language: Ş (Turkish, #E2574C), Я (Ukrainian, #2F6FB3), あ (Japanese, #E9A23B), ع (Arabic, #2E8B6E) on cream (#F6F1E7). The letters are outlines taken from Georgia, Yu Gothic Bold and Sakkal Majalla Bold.

| File | Use |
| --- | --- |
| `lisan-icon-512.svg` / `.png` | Google Play store icon (512 x 512, full square; Play rounds the corners). Already uploaded to the Play listing. |
| `lisan-adaptive-foreground.svg` | Android adaptive icon foreground (108 dp canvas, content inside the 66 dp safe zone). |
| background colour `#F6F1E7` | Android adaptive icon background (solid). |
| `lisan-monochrome.svg` | Android 13+ themed icon (single colour, alpha only). |

All shapes are plain paths: no fonts are needed to render them.
