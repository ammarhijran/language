# App icon (chosen by the owner on 2026-11-23: "tea and talk")

A Turkish tea glass (glass #F4D9A8, tea #C8692B) on a red saucer (#E2574C), its steam curling up into a
cream speech bubble (#FBEFDC) holding four dots in the course colours (#E2574C, #2F6FB3, #E9A23B, #2E8B6E),
on terracotta (#7A2F1F). Everyday conversation over tea. It replaces the white speech bubble on red, which
the owner found generic, and an earlier four-tile draft that the owner rejected.

The file names carry no app name because the store name is still being chosen ("Lisan" is taken on Play).

| File | Use |
| --- | --- |
| `app-icon-512.svg` / `.png` | Google Play store icon (512 x 512, full square; Play rounds the corners). |
| `app-adaptive-foreground.svg` | Android adaptive icon foreground (108 dp canvas, drawn at 0.76 so it fits the round mask). |
| background colour `#7A2F1F` | Android adaptive icon background (solid). |
| `app-monochrome.svg` | Android 13+ themed icon (single colour, alpha only). |

All shapes are plain paths: no fonts are needed to render them.
